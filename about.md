# About

![Yadurshan Rajakumar in Colombo, with the Lotus Tower behind him](/images/yadurshan.jpeg){.portrait}

I'm Yadurshan Rajakumar, a full stack developer based in Colombo, Sri Lanka.

Since September 2024 I've worked as an Associate Blockchain Developer at Coinceylon. Most days I'm writing TypeScript and Node.js with MeshSDK and Plutus for onchain features. I also set up and look after the Ubuntu server we run on at Hetzner, including a Cardano node I use to test indexers like Dolos and cardano-db-sync. I also run live product demos for partners and clients, and act as the link between them and our engineers.

I started this blog to write down what I learn while building, so the next developer has an easier time than I did.

## Projects

**LankaNFT** is an NFT minting and marketplace platform. It has a Go REST API, a Node.js transaction service and Aiken smart contracts, and people can sign in with an email address or an external wallet, so they don't need to know anything about crypto to use it.

**Adalytics** tracks 360 Cardano tokens with live prices, charts and trade history. The Go backend gets by on about three API requests a minute and 25 MB of memory.

**HealthTrust** was my final year project: an insurance claims platform where a Python service flags likely fraud and Aiken contracts on Cardano Preprod handle payouts. I also wrote its go to market plan, covering segmentation, SEO, GA4 tracking and an email campaign.

The code for these is on [GitHub](https://github.com/Yadurshan-R).
